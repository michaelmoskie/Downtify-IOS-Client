# Agent handoffs

Use this folder for focused implementation task briefs and handoffs. Each agent receives only the information needed for one task and ends after completing it. The coordinator reviews and integrates the result before assigning dependent work.

See the [porting plan](../docs/PORTING_PLAN.md) for task assignments and the [Android parity audit](../docs/ANDROID_PARITY_AUDIT.md) for source findings.
